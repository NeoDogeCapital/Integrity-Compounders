X = Revenue Momentum = Fwd Rev CAGR − Trailing Rev 3Y CAGR. Y = Earnings Momentum = Fwd EPS CAGR (capped 25%) − Trailing EPS 3Y CAGR. Both measure acceleration against a company's own history, not absolute growth — a fast grower that is slowing plots left, a modest grower that is speeding up plots right.
Quadrant assignment follows engines/quad.py::_assign_quadrant and CLAUDE.md §5.2; verified consistent on 277/277 names. Zero is treated as non-negative (X=0 or Y=0 → the upper/right side), which differs from §5.2's stated conservative tie-break.
A first-time move into a new quadrant is provisional — §5.2 requires two consecutive month-ends before a migration counts as signal.
